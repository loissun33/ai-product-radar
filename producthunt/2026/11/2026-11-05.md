## 🔍 Product Analysis

### 🥇 #1 Glasshand — 305 votes · 71 comments

> **Tagline**: Give your agent a real iPhone and Mac

| | |
|---|---|
| 🌐 Website | [glasshand.com](https://glasshand.com/) |
| 🏹 Hunter | — |
| 👷 Makers | Codapt Inc. |
| 🏷️ Tags | AI Agents · Mobile · Developer Tools · Automation |

Glasshand is the first platform to provision real, dedicated iPhones and Mac Minis in a data center and rent them to AI agents via API. Unlike emulators or virtual machines, Glasshand offers genuine hardware — which means agents bypass fingerprinting, can install App Store apps, sign into iCloud and personal accounts, and receive real SMS through an eSIM plan. Agents connect through the Glasshand API and interact with the device the same way a human does: seeing the screen and sending taps, swipes, and keystrokes. Each device is exclusive to one customer and factory-reset on release. The company behind it is Codapt Inc. and it works with any agent framework including Claude Code, Codex, Cursor, OpenClaw, and Hermes.

#### Six-Dimension Deep Dive

| Dimension | Analysis |
|-----------|----------|
| 🎯 **Positioning** | "Real device as a service" for AI agents. When most agents hit a wall with apps that have no API, Glasshand hands them a physical phone — unlocking the full mobile surface area that software-only approaches cannot reach. |
| ⚙️ **Core Features** | Dedicated real iPhone & Mac Mini → API-driven screen, touch, and keyboard control → eSIM with real phone number for SMS/iMessage → App Store access → iCloud and account sign-in → data persists across tasks until device is released |
| 💡 **Tech Highlight** | Real hardware sidesteps device-fingerprinting detection used by Instagram, TikTok, and LinkedIn. eSIM activation solves the SMS verification bottleneck that stops most automation stacks. Compatible with any AI agent framework out of the box. |
| 👥 **Target Market** | Solo founders and agencies automating social media accounts (Instagram, TikTok, LinkedIn replies, DMs, lead follow-up); iOS developers who need agents to build and test native apps in Xcode; anyone running tasks that require a real phone's identity. |
| 📈 **Growth Signal** | #1 on November 5 with 305 votes and 71 comments — the largest vote gap between #1 and #2 (111 votes) in recent weeks. The concept of real hardware for agents is rare, generating high organic media attention and a lively comment section. |
| ⚠️ **Risk** | Physical device maintenance and hardware costs are non-trivial to scale; platforms like TikTok may update bot-detection responses over time; month-to-month rental is expensive for low-frequency use cases; early-stage company reliability is unproven at scale. |

### 🥈 #2 Rerun — 194 votes · 12 comments

> **Tagline**: Turn your AI subscriptions into a team of coworkers

| | |
|---|---|
| 🌐 Website | [rerun.build](https://rerun.build/) |
| 🏹 Hunter | — |
| 👷 Makers | Clément Janssens · Théo Louro (Reunit SA) |
| 🏷️ Tags | Artificial Intelligence · Productivity · Automation · Open Source |

Rerun is an open-source (AGPL-3.0) platform for hiring AI coworkers that run on your existing AI subscriptions — ChatGPT, Claude, Grok, or any OpenRouter model. You describe the job in a sentence, and an AI Foreman builds a coworker for you: one with its own memory, tools, integrations, and a dedicated cloud computer that runs 24/7. Rerun supports 200+ integrations natively (Gmail, Slack, Notion, HubSpot, Stripe, Shopify) and 2,000+ apps through Composio. Coworkers pause for human approval before consequential actions like sending emails or pushing code. The platform is fully self-hostable; Rerun Cloud adds a template library, included AI credits, and official support. Founded by Clément Janssens and Théo Louro (Reunit SA).

#### Six-Dimension Deep Dive

| Dimension | Analysis |
|-----------|----------|
| 🎯 **Positioning** | "Open-source AI employee company." Rather than adding AI to a workflow tool, Rerun gives each job its own AI teammate that actually does the work. The key insight: your existing Claude or ChatGPT subscription already includes the intelligence — Rerun adds the body (computer, memory, integrations). |
| ⚙️ **Core Features** | AI Foreman that interviews you and builds the team → each coworker has its own cloud machine, memory, and skills → 200+ integrations + 2,000+ apps via Composio → human-in-the-loop approval before high-stakes actions → real-time run monitor → scheduling and webhook triggers → fully self-hostable |
| 💡 **Tech Highlight** | Each workspace gets an isolated, persistent cloud machine in Europe — no shared infra, no data leakage. Tech stack is Next.js + Supabase + Docker, fully open under AGPL-3.0, so self-hosters can inspect every line. The model-agnostic design means coworkers switch between Claude, GPT-6, and Gemini per task. |
| 👥 **Target Market** | Agencies, e-commerce owners, freelancers, recruiters, and legal/compliance teams that have recurring workflows they currently handle manually; startups that want to scale operations without proportional headcount growth; developers who want to self-host an AI team on their own infra. |
| 📈 **Growth Signal** | Launched alongside a public GitHub repo that positions Rerun as the open-source alternative to Dots, Duet, and Grok Bot. 2,000+ reported users. Free 5-day trial lowers onboarding friction. Two-founder direct support through email and Discord maintains strong community trust. |
| ⚠️ **Risk** | AI agents still hallucinate and make mistakes in complex multi-step business tasks; competing with mature no-code automation platforms (Make, Zapier, n8n) that have large head starts; AGPL licensing creates tension with enterprise sales; European hosting may limit latency for US/APAC users. |

### 🥉 #3 Living Brain — 181 votes · 37 comments

> **Tagline**: Interoperable, efficient memory layer for agentic AI

| | |
|---|---|
| 🌐 Website | [chatandbuild.com](https://chatandbuild.com/) |
| 🏹 Hunter | — |
| 👷 Makers | ChatAndBuild Team |
| 🏷️ Tags | AI Agents · Memory · Developer Tools · Infrastructure |

Living Brain is ChatAndBuild's AI memory infrastructure product — a persistent, self-learning shared memory layer that any AI agent can tap into through API, SDK, or MCP. It solves the core problem with today's agents: every conversation starts from scratch. With Living Brain, agents can store, retrieve, and build on context across sessions, users, documents, and tools. The product ships with 30 memory types and 36 connection patterns, organized into 12 research packs covering agents, memory, reasoning, evaluation, and safety. The company behind it has backing from Google, Anthropic, OpenAI, and NVIDIA's Inception Program. Existing ChatAndBuild plan subscribers receive access to Living Brain alongside ChatChat (their agent messenger) and Abundant Intelligence (their AI learning modules).

#### Six-Dimension Deep Dive

| Dimension | Analysis |
|-----------|----------|
| 🎯 **Positioning** | "The hippocampus for AI agents" — a universal memory middleware layer. The pitch is interoperability: Living Brain is not locked to one framework or one company's ecosystem. Any agent that can hit an API or MCP server can use it, and it gets smarter with every session. |
| ⚙️ **Core Features** | Persistent cross-session memory → self-learning memory updates → API + SDK + MCP protocol support → 30 memory types, 36 connection patterns → shared memory across team members → 12 curated research memory packs → searchable 30-node memory graph |
| 💡 **Tech Highlight** | MCP compatibility means zero-friction integration into the growing ecosystem of MCP-native agents (Claude, Cursor, etc.). The "self-learning" design improves recall precision over time without manual curation. Four major AI companies (Google, Anthropic, OpenAI, NVIDIA) have backed or endorsed the team, lending significant technical credibility. |
| 👥 **Target Market** | Developers building multi-session AI agent applications; enterprise teams that need agents to maintain context across users and projects; existing ChatAndBuild users seeking memory across their personal AI ecosystem; researchers building memory-augmented AI systems. |
| 📈 **Growth Signal** | 37 comments reflects strong developer interest and discussion. Four-company backing signals industry recognition of the memory-layer category. The MCP boom creates a natural distribution channel — any tool that adopts MCP can plug in Living Brain with minimal setup. |

## 📈 Trend Summary

**1. Real and dedicated hardware is becoming the new AI agent moat.**

November 5 saw two products — Glasshand (#1) and Maritime (#4, YC F26) — attack the same problem from opposite ends of the hardware stack. Glasshand gives agents real iPhones for mobile automation; Maritime gives agents isolated persistent VMs (Linux, Windows, Android) for server-side compute, priced at $1/agent/month with three free agents to start. Both bets share the same thesis: as agent capability increases, software emulation becomes the bottleneck, and teams that own the compute layer will compound structural advantages over API-only competitors.

**2. Human-in-the-loop is graduating from safety feature to revenue line.**

Pushary for Teams (#5) has built an entire product around the approval record — the shared log that shows who said yes to each AI agent action. At $59/month for a five-person team, it has found a paying audience among engineering teams running Claude Code, Codex, and Cursor. Rerun (#2) makes human approval a first-class design constraint: coworkers pause before sending, paying, or deleting. Both products reflect the same market signal — as agents gain access to more consequential actions (production deploys, customer emails, database writes), the oversight layer is no longer optional for teams, and they will pay for a clean interface to manage it.

**3. The agent infrastructure stack is crystallizing around three layers: compute, memory, and control.**

Living Brain (#3) adds a durable memory layer backed by Google, Anthropic, OpenAI, and NVIDIA — the fourth major memory-infrastructure product to chart in the PH top 5 this November (following beacon.sh on Nov 2). Maritime (#4) anchors the compute layer. Pushary (#5) anchors the control layer. What's emerging is not a single agent platform but a composable stack: developers pick their compute (Maritime, Glasshand), their memory (Living Brain, Mem0), and their control surface (Pushary, Rerun's built-in approvals). Products that solve one layer cleanly are winning on PH; products that try to own all three are facing sharper differentiation questions.
