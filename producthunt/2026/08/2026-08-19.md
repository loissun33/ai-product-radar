### 🥈 #2 Clipto MCP — 447 votes · 107 comments

**Tagline:** Fully local, natural language search over terabytes of media  
**Website:** [clipto.ai](https://clipto.ai/)  
**Makers:** Henry Kang, Luke, Freya Fang, Matthewwei  
**Tags:** AI · Media Search · MCP · Developer Tools · Privacy  
**Rating:** 4.6/5 (9 reviews) · 1.5K followers

**What it does:** Clipto MCP gives Claude, ChatGPT, and other AI agents the ability to search and source clips from your personal local media library — videos, audio recordings, images — all without uploading a single file to the cloud. Users can match scripts to footage, pinpoint moments across years of recordings, and generate rough cuts using natural language. The MCP integration means your existing AI chat interface becomes your media editor.

**Growth signal:** 447 votes and 107 comments — the highest comment count of the day, signaling deep community engagement. A free month promo (PHLNCH) is accelerating trial adoption.

**Risk:** Collaboration use cases are limited by local-only storage; depends on MCP protocol adoption continuing to grow.

### 🥉 #3 Origin by Cursor — 319 votes · 9 comments

**Tagline:** The Git forge built for the age of coding agents  
**Website:** [cursor.com](https://cursor.com/)  
**Makers:** Cursor Team (11th product launch)  
**Tags:** Developer Tools · AI · Git · Code Hosting · GitHub Alternative  
**Pricing:** Free

**What it does:** Origin is Cursor's new code hosting platform — a GitHub alternative purpose-built for the era where AI agents are the primary code authors. It provides native Git repository hosting, code browsing and search, pull request management, access control, and bidirectional GitHub synchronization, all within an architecture designed for machine-readable diffs and agent-friendly review workflows. When agents are generating hundreds of PRs daily, traditional human-centric review UI becomes the bottleneck; Origin reimagines the full collaboration surface.

**Growth signal:** 319 votes; Cursor has a massive built-in user base as the leading AI coding agent. GitHub's reliability issues and the rise of autonomous coding agents make the timing acute.

**Risk:** GitHub's network effects are extraordinarily deep; teams that still rely on human visual diff review see limited switching benefit in the short term.

### 4️⃣ #4 Claude Watermark Remover — 245 votes · 15 comments

**Tagline:** Detect and remove Claude's formatting artifacts from text  
**Website:** [claudewatermarkremover.app](https://claudewatermarkremover.app/)  
**Maker:** Ofir Smolinsky  
**Tags:** AI Tools · Text Processing · Developer Tools · Open Source  
**Pricing:** Free · MIT licensed

**What it does:** Following Anthropic's announcement of text watermarking for Claude output, this tool was built to detect and remove the *formatting-layer* artifacts that appear when copying Claude-generated text — hidden HTML class names, zero-width characters, exotic spaces, and typography markers. It runs entirely in the browser (no data uploaded), provides exact counts and positions for every finding, and optionally rewrites text to alter wording patterns. Importantly, the creator is explicit that this tool **cannot** detect Anthropic's statistical watermark (which requires keys only Anthropic holds). That transparency earned significant community praise.

**Growth signal:** 245 votes; community reaction to Anthropic's watermark announcement drove rapid developer interest in the tool. The honest scope communication built trust.

**Risk:** Only addresses the formatting layer; as AI detection technology matures, the product's value proposition may narrow.

### 5️⃣ #5 Hosted Agents in Cluing — 181 votes · 26 comments

**Tagline:** Collaborative agents who build, learn and publish in 1 place  
**Website:** [cluing.io](https://cluing.io/)  
**Makers:** Cluing Team (formerly Collabwriting)  
**Tags:** AI Agents · Knowledge Management · MCP · Productivity · Teams  
**Rating:** 4.9/5 (9 reviews) · Pricing: Free tier available; $12/mo Pro; $120/mo Superhuman

**What it does:** Cluing (formerly Collabwriting) launched hosted agent support — meaning AI agents now run continuously in the cloud without requiring the user's device to stay online. Teams can assign tasks, agents build and update knowledge graphs from web pages, PDFs, and email newsletters, and all outputs are shared across the team without context loss. The system integrates into Claude, ChatGPT, Codex, and Perplexity via MCP. This is Cluing's 8th Product Hunt launch, reflecting a steady evolution from collaborative writing tool to full AI agent platform.

**Growth signal:** 181 votes, 26 comments; the 4.9/5 rating (from 9 reviews) is the highest-rated product of the day. The pivot from writing tool to persistent agent platform is resonating.

**Risk:** Competing directly with Notion AI, Mem, and other knowledge management + AI platforms that are also evolving rapidly; repositioning requires existing users to re-learn the product.

## 📈 Trend Summary

1. **AI enters the B2B marketing stack at the partnership layer** — Astute's #1 finish marks a shift: B2B brands are no longer just using AI to generate content, they're using it to manage entire creator relationship pipelines. This is creator economy infrastructure for the enterprise, and the market is just waking up to the opportunity.

2. **Privacy + MCP = the local AI flywheel** — Clipto MCP's 447 votes and highest-comment-day record shows that "local-first, private by default" is becoming a real competitive advantage, not just a marketing claim. As MCP becomes the universal connection protocol for AI tools, any product that hooks into it with privacy-first positioning is sitting in a powerful distribution channel.

3. **Code infrastructure is being rebuilt for the agent majority** — Origin by Cursor's #3 ranking signals that the developer tooling layer is actively being re-architected. When agents write most of the code, the review, storage, and collaboration interfaces must change with them. GitHub's dominance is not guaranteed in a world where the primary committer is a machine.
