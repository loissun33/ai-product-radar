### 🥇 第 1 名：ayghri/i-have-adhd

**🔗 项目链接：** https://github.com/ayghri/i-have-adhd

**解决的问题：** AI 编程 Agent（Claude Code、Codex 等）在输出代码或分析结果时，习惯于将核心答案埋藏在大量背景叙述、警告声明和次要信息中，导致用户——尤其是注意力分散型用户——难以快速定位关键信息。i-have-adhd 通过技能层约束 Agent 的输出结构，强制将答案、行动项和关键代码优先呈现于响应开头。

**亮点与创新：**
- ADHD 友好输出模式：核心结论优先、消除冗余、语言简洁直接
- 一键安装：通过 CLI 提示词即可全局加载，无需复杂配置
- 多语言 README 支持（中文、英文、日文、越南文、韩文、泰文、葡萄牙文），国际化程度高
- 开放给所有用户，无需 ADHD 诊断，实际上提升所有工程师的信息密度效率
- MIT 开源，Topics 包含 claude-code-plugin、claude-skills、developer-tools

**采用信号：** 30,405 总 Stars，1,853 Forks，31 个 open issues，最近更新 2026-09-08，社区维护活跃。

**适用人群：** 所有使用 AI 编程工具的开发者，尤其是希望提升 Agent 输出信噪比、减少信息过载的团队和个人。

**风险与关注点：** 技能本质上是 prompt 层约束，存在被 Agent 忽略的风险；输出风格过于简洁可能在复杂推理场景下丢失必要上下文。主要维护者依赖度未知，长期可持续性需观察。

**许可证：** MIT ｜ **维护者：** ayghri（个人维护）

## 🥇 第一名深度解析：ayghri/i-have-adhd

### 1. 项目定位

ayghri/i-have-adhd 本质上是一个"认知效率技能"——它不优化代码质量，而是优化 AI Agent 的信息呈现方式。在 AI 编程工具普及的背景下，开发者每天面对的不是算力不足，而是信息过载：Agent 的回答冗长、核心答案被埋藏、行动项不清晰。此技能通过约束输出结构，将 ADHD 友好设计原则（简洁、优先、直接）应用于 AI 输出层，本质上是一个"信号提取器"。

### 2. README 与文档质量

文档质量高，覆盖 7 种语言（含中文），国际化设计完善。安装方式极简（一行 CLI 提示词），INSTALL.md 独立提供详细说明，README 结构清晰，即使非英语母语用户也能快速上手。多语言支持说明维护者有意构建国际化社区。

### 3. 增长与社区指标

今日新增 656 Stars，总 Stars 30,405，Forks 1,853，open issues 31。Topics 包含 claude-code-plugin、claude-skills，与目前 GitHub Trending 主流生态深度绑定。增长态势稳健，未见异常波动。

### 4. 维护者与生态分发

单人维护（ayghri），尚无明显商业背景，但维护活跃（最近更新 2026-09-08）。项目依托 AGENTS.md 标准分发，与 Claude Code Plugin 生态兼容，是当前 AI 技能包分发的主流路径之一。项目没有商业压力，开源纯粹。

### 5. 相对优势

对比同类"输出优化"技能，i-have-adhd 胜在定位精准（专注输出结构而非内容）、安装门槛极低、多语言文档支持广泛。其名称本身就是一个记忆点，病毒传播性强。在以"技能炸弹"为主的 Trending 榜上，它是一个纯粹聚焦"用户体验"的异类，差异化显著。

### 6. 风险与不确定性

技能的核心价值取决于 Claude Code 等 Agent 遵守 prompt 约束的程度，随着模型版本更新，效果可能变化。单人维护意味着维护连续性存在不确定性。此外，当越来越多的"输出优化"技能进入市场，未来的竞争分散化可能影响其持续排名。
