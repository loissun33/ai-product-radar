### 🥇 1. deepseek-ai/deepseek-harness

**地址：** https://github.com/deepseek-ai/deepseek-harness

**解决的问题：** 传统 Agent 框架存在"特权核心"问题——修改任何核心组件需要打补丁重启整个系统。deepseek-harness 通过 Cordis 插件内核，将模型适配器、工具注册表、会话日志、沙箱、Agent 循环、调度、UI 全部设计为可热插拔插件，彻底解决了扩展性与可维护性问题。

**亮点与创新：**
- 哲学理念："Everything is a Plugin"——包括模型、工具、技能、会话、沙箱、存储、循环、调度及 UI
- 基于 Cordis 框架，该框架已在生产环境运行超4年，社区贡献插件超4,000个
- 附带88页同行评审论文，正式化插件架构的组合保证
- 支持 DeepSeek、Anthropic、OpenAI 及任意 OpenAI 兼容端点
- 本地 Web UI（127.0.0.1:3080）、无头 CLI、Python SDK 三种接口
- 包含 Memory、上下文压缩、主动调度等社区插件（上线24小时内涌现）
- GitHub Issues 已关闭，反馈通过 Discussions 和 Discord 处理

**采用信号：** 发布10天内破18.5万颗星，峰值速度约2,100颗/小时，刷新 GitHub 历史纪录。与 Anthropic 竞争对手 Claude Code 共存，CLAUDE.md 文件同时引用 AGENTS.md，显示开放的生态兼容性。

**适合人群：** Agent 框架开发者、AI 基础设施工程师、希望构建可扩展插件化 Agent 系统的团队。

**风险与关注：** 仍处于开发者预览（v0.1.0-rc.5），明确警告存在"兼容性破坏性变更"。插件生态质量参差不齐，学习曲线较陡峭。Token 使用成本较高。

## 🥇 第一名深度解析：deepseek-ai/deepseek-harness

### 1. 项目定位

DeepSeek Harness（命令：`dsh`）是 DeepSeek AI 于2026年8月13日发布的开源 Agent Harness 框架。其核心定位是"连接语言模型与真实世界的基础设施层"——涵盖文件系统、Shell 命令、工具调用、会话管理、审批流程和长运行工作流。与其他 Agent 框架不同，DSH 不提供任何"特权核心"，所有功能均通过插件层暴露，理论上任何组件都可在运行时被热替换。

### 2. README / 文档

项目文档包括：
- 清晰的安装指南（Node 22.19+/24+，`npm i -g @deepseek/dsh`）
- 四种运行时模式说明（Standard、Code、Minimal、Creator）
- 插件开发文档（`dsh-plugin` 话题标签用于可发现性）
- 88页同行评审论文，为架构设计提供学术背书
- 根目录 CLAUDE.md 引用 AGENTS.md，显示多模型设计意图

文档质量：**优秀**——具备完整的快速上手、概念解释和开发者指南，开源早期即有完整的概念文档，这在大模型开源项目中较为罕见。

### 3. 增长与社区指标

| 指标 | 数据 |
|------|------|
| 发布日期 | 2026-08-13 |
| 10天总星数 | ~185,400 |
| 峰值增长速度 | ~2,100颗/小时 |
| Forks | ~20,500 |
| 社区渠道 | Discord（Issues 已关闭，以 Discussions 为主） |
| 生态插件 | 上线24小时内出现 Memory、上下文压缩、主动调度插件 |
| 历史对比 | 被多篇分析文章称为"GitHub 历史最快星数增长记录" |

### 4. 维护者 / 生态分发

- **维护方：** DeepSeek AI（官方 GitHub 组织 `deepseek-ai`），北京大学合作
- **技术底座：** Cordis 框架（开源插件内核，已有4年+生产运行记录，4,000+社区贡献插件）
- **生态信号：** dshplugin.dev（第三方插件目录）、deepseek-harness-desktop（anywhere-labs 开发的桌面端）、awesome-dsh-plugin 精选目录迅速形成，显示社区自发的生态建设势头
- **学术背书：** 88页论文为插件架构提供正式化的理论保障

### 5. 相对优势

与同类 Agent 框架（LangChain、AutoGen、Claude Code、openai/codex）相比：
- **最彻底的插件化**：其他框架有"核心不可插拔"的部分，DSH 理论上无一例外
- **生产级底座**：Cordis 框架有4年+实战验证，非从零构建
- **模型中立**：不绑定特定 LLM 提供商，原生支持 DeepSeek/Anthropic/OpenAI
- **学术支撑**：同行评审论文为设计决策提供理论依据，有利于企业采购说服力
- **兼容竞争对手**：CLAUDE.md 的存在表明主动支持 Anthropic 生态，降低迁移摩擦

### 6. 风险与不确定性

- **早期预览风险：** v0.1.0-rc.5 明确存在破坏性变更，生产使用需谨慎
- **Token 成本：** 插件化架构意味着每次操作可能产生更多 LLM 调用，成本较高
- **中国背景合规风险：** DeepSeek AI 的中国公司背景可能使部分企业在合规审查上面临额外障碍（数据主权、出口管制等），需个案评估
- **生态质量控制：** 开放插件生态在快速扩张期质量参差不齐，恶意插件风险需关注
- **竞争格局：** OpenAI、Anthropic 均有成熟终端代理（Codex CLI、Claude Code），网络效应已建立，DSH 需在差异化上持续证明价值
