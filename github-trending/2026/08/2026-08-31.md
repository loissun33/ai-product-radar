## 逐项分析

### 1. sapientinc/PRAXIST ⭐ 今日 +647

**URL：** https://github.com/sapientinc/PRAXIST  
**语言：** Python | **许可证：** Fair Source 1.0  
**维护方：** Sapient Intelligence（美国初创公司，@Sapient_Int）

**解决的问题：** 传统 AI 编码智能体（如 Claude Code、OpenAI Codex）以会话为单位运行，每次实验的教训无法跨代积累。PRAXIST 引入了"耐久证据协议"（durable evidence protocols），将每次实验的发现——包括正面、负面、诊断性、不确定结论——作为一类数据结构传递给下一轮迭代，从根本上解决了 AI R&D 的"记忆失忆"问题。

**核心亮点：**
- 并行研究同伴架构（分析者、探索者、创新者、利用者、证伪者、整合者），由 PI Panel（建造者/怀疑者/组合者）统一调度
- 在 MLE-bench 完整 75 任务上取得 49 枚金牌（65.3%），60 枚总奖牌（80%），使用 deepseek-v4-pro
- 模型成本约 $3,054，对比 Claude Code + Opus 4.8 基线的 ~$38,370，节省约 92%
- 金牌数比 Claude Code 基线高出 44%

**适合人群：** ML 研究工程师、需要进行可重复性实验的科研团队、AI 基础设施建设者。

**风险与隐患：**
- Fair Source 1.0 许可证为"源码可见但商业受限"，企业部署需确认合规
- MLE-bench 成绩依赖特定环境，部分任务（SLAM、火箭着陆）使用合作伙伴定制评测环境，存在选择性过拟合风险
- $3k 成本仅为模型调用费，不含完整算力开销
