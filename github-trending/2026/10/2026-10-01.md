### #1 · debpalash/VoiceStudio
**https://github.com/debpalash/VoiceStudio**

**解决的问题：** ElevenLabs 等商业语音合成服务价格高昂，且数据必须上传至云端，存在隐私与成本双重顾虑。VoiceStudio 提供完全本地化方案，让开发者与内容创作者在自有硬件上无限制地使用语音克隆、视频配音等能力。

**亮点与创新：** 支持多达 646 种语言，覆盖范围远超绝大多数商业产品；本地执行消除 API 调用费用，允许无限制实验；功能涵盖语音设计、视频配音、自动转录听写、有声书制作，形成完整的语音生产链。

**采用信号：** 近七日新增约 16,000 颗星，总星数约 51k，Forks 约 5,600，显示出强劲社区复现意愿。技术博客与媒体广泛报道，被定位为最值得关注的 ElevenLabs 开源替代方案之一。

**适用人群：** 多语言内容本地化团队、独立播客与有声书作者、对数据主权有高要求的企业（金融、医疗、法律行业）、希望降低语音 API 成本的 AI 应用开发者。

**风险与隐患：** AGPL-3.0 协议意味着在商业产品中集成需谨慎，任何派生作品需同样开放源码；本地运行的硬件门槛未知；646 语言声称需独立验证各语言质量水平，边缘语言效果可能参差不齐。

**协议：** AGPL-3.0 | **维护者：** debpalash（单一维护者，贡献集中度风险）

### #7 · NandhaKishorM/laya
**https://github.com/NandhaKishorM/laya)**

**采用信号：** 近七日新增约 7.7k 颗星，总星数约 29k；HuggingFace 上已有模型镜像（nishanth-kj/laya），多语言博客解读说明社区关注度较高；aiweekly.co 等 AI 资讯平台收录报道。

**适用人群：** 需要在本地低延迟判断用户意图/内容类别的 AI 应用开发者、希望为 RAG pipeline 添加快速路由决策层的工程师、对 jev 等商业决策 API 有替代需求的团队。

**风险与隐患：** 零样本精度仅 0.362，微调后达 0.766，实际落地需投入微调成本（约需 2 个 T4 GPU 和 4 小时）；非自回归架构的局限性使其不适合需要复杂推理的场景；Convai Innovations 背景信息披露有限。

**协议：** Apache-2.0 | **维护者：** NandhaKishorM（Convai Innovations）

### 2. README/文档
